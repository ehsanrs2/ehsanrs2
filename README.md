## Featured open-source project

### 📅 [Forex Factory Economic Calendar Scraper (Python)](https://github.com/ehsanrs2/forexfactory-scraper)

Collect and normalize Forex Factory economic calendar events into a persistent CSV cache. The project supports incremental historical updates, timezone-aware data, filters, and duplicate validation.

- [**Source code and Quick Start**](https://github.com/ehsanrs2/forexfactory-scraper)
- [**Historical economic calendar dataset on Hugging Face**](https://huggingface.co/datasets/Ehsanrs2/Forex_Factory_Calendar)

Useful for financial-data research, historical event studies, backtesting workflows, and ML feature engineering. Live scraping is subject to the source site's access restrictions.
